## Overview
The Create Forecast Scenario Variants feature allows users to generate multiple versions of a base forecast scenario. This helps analyze different assumptions, compare outcomes, and support decision-making through structured scenario planning.

## Who should use this
Financial Analysts responsible for evaluating multiple forecasting assumptions and comparing potential financial outcomes.

## Prerequisites
- Access to the forecasting module
- An existing base forecast scenario
- Required permissions to create and modify forecast variants

## Steps
1. Navigate to the Forecasting module.
2. Select an existing forecast scenario to use as the base.
3. Click **Create Variant**.
4. Enter a name and description for the variant.
5. Modify key inputs such as assumptions, drivers, or time periods.
6. Save the variant.
7. Repeat the process to create additional variants as needed.
8. Use the **Version Comparison** feature to review differences across variants.
9. Submit the preferred variant for approval.

## Tips and best practices
- Use a consistent naming convention to identify variants easily.
- Clearly document the assumptions for each variant.
- Limit the number of changes per variant for clearer analysis.
- Regularly compare variants to track impact of changes.
- Validate data before submitting for approval.

## Troubleshooting
- **Unable to create a variant**: Ensure a base scenario is selected and permissions are enabled.
- **Changes not reflected**: Verify that edits are saved correctly.
- **Comparison issues**: Confirm that variants are aligned in structure and time period.
- **Approval not progressing**: Check if the correct approver is assigned.
- **Unexpected results**: Review modified assumptions and input data.END
